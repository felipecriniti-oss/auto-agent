Create a new file `scripts/probe-apify-tier.ts` (Node 22+ runnable via `pnpm tsx scripts/probe-apify-tier.ts`). Exact behavior (concrete values — do NOT improvise):

1. Read `process.env.APIFY_API_TOKEN`. If missing, print `MISSING APIFY_API_TOKEN` to stderr and `process.exit(2)`.

2. Define constants:
   - `const APIFY_BASE = "https://api.apify.com/v2";`
   - `const ACTOR = "ribtools~webmotors-scraper";`

   - `const MAX_ITEMS = 10;` (tiny — we only need to confirm Akamai is bypassed)
   - `const POLL_INTERVAL_MS = 5_000;`
   - `const TIMEOUT_MS = 180_000;` (3 min total budget)

3. POST to `${APIFY_BASE}/acts/${ACTOR}/runs?token=${encodeURIComponent(token)}` with JSON body:
   ```typescript
   {
     startUrls: [{ url: TEST_URL }],
     maxItems: MAX_ITEMS,
     proxyConfiguration: { useApifyProxy: true, apifyProxyGroups: ["RESIDENTIAL"] }
   }
   ```
   Headers: `Content-Type: application/json`, `Accept: application/json`. Use `AbortSignal.timeout(TIMEOUT_MS)`.

4. Extract `runId = postJson.data.id`, `defaultDatasetId = postJson.data.defaultDatasetId`. Print `Started run runId=${runId}`.

5. Poll `GET ${APIFY_BASE}/actor-runs/${encodeURIComponent(runId)}?token=${encodeURIComponent(token)}` every `POLL_INTERVAL_MS` until `data.status` is one of `SUCCEEDED`, `FAILED`, `ABORTED`, `TIMED-OUT`. Maximum total wall time = `TIMEOUT_MS`. If timeout exceeded, abort and print `RESULT: HALT — run did not complete within 3 minutes`.

6. After terminal status:
   - If `status === "SUCCEEDED"`: GET the dataset (`${APIFY_BASE}/datasets/${defaultDatasetId}/items?clean=true&limit=10&token=${encodeURIComponent(token)}`). Count items. Print:
     ```

     status=SUCCEEDED
     itemCount=<N>
     usageTotalUsd=<value or null>
     statusMessage=<value>
     ```
     Exit 0.
   - If `status` is anything else (`FAILED` / `ABORTED` / `TIMED-OUT`): print `RESULT: HALT` plus the full `statusMessage` (token-scrubbed). Exit 1.

7. ALL `console.error` / `console.log` / thrown errors MUST pass through token-scrub: `String(x).replace(new RegExp(token, "g"), "[REDACTED]")`. Apply this to every output of the script — no exceptions.

8. The script MUST be re-runnable safely (no side effects beyond starting one small Apify run that costs ~$0.01 USD). Use only built-in `fetch`. NO npm dependencies added.
