# Quick Task 260422-002

## Context

Two user-reported issues:

1. **Logo swap:** `/logo.jpeg` (wide wordmark, 520x180) → `/autoagente-whatsapp.svg` (square 400x400 badge, cream bg `#F5F3EE`, purple mark `#4C46DC`). Used in: Sidebar mobile top bar, Sidebar desktop header, SignupView header.
2. **Dark mode quality issues:** colors clash, contrast fails WCAG in several places, hover states disappear.

## Dark-mode diagnosis (from reading `src/app/globals.css`)

| Class | Current dark mapping | Issue | Proposed fix |
|---|---|---|---|
| `.text-slate-300` | slate-600 (rgb 71,85,105) | ~2.2:1 on slate-900 bg — fails WCAG | slate-400 |
| `.text-slate-400` | slate-500 (rgb 100,116,139) | ~3.5:1 — fails normal text AA | slate-400 |
| `.text-slate-600` | slate-400 | body text at 5.8:1 — OK but feels gray | slate-300 |
| `.text-slate-700` | slate-300 | already fine (9.5:1) | keep |
| `.hover:bg-slate-100` | slate-900 | same color as `.bg-white` → hover invisible | slate-800 |
| `.hover:bg-slate-50` | slate-950 | same as page bg → hover invisible | slate-900 |
| `.border-slate-200` | slate-800 | slate-800 on slate-900 bg barely visible | slate-700 |
| body `--background` | oklch(0.145 0 0) neutral gray | clashes with slate-950 surfaces | slate-950 rgb |
