# Quick Task 260422-002 — Summary

## Logo swap

Replaced every `/logo.jpeg` reference (3 sites) with the provided `/autoagente-whatsapp.svg`. The old asset was a wide wordmark (520×180); the new one is a square 400×400 badge (cream #F5F3EE bg, purple #4C46DC mark). To preserve the "brand + name" read, each site now renders the SVG as a small rounded-xl square avatar **paired with an explicit "AutoAgente" wordmark span**.

**Files:**
- `src/components/v3/Sidebar.tsx` — mobile top bar (h-7 w-7) + desktop header (h-9 w-9)
- `src/components/v3/SignupView.tsx` — landing/signup header (h-10 w-10)

In dark mode each avatar gets a `ring-1 ring-slate-800` so the cream-bg badge doesn't float on slate-950 without a defined edge.

## Dark mode rework

Two-level surface system clarified in the comment block of `src/app/globals.css`:

| Role | Color | rgb |
|---|---|---|
| Page bg | slate-950 | 2 6 23 |
| Card bg | slate-900 | 15 23 42 |
| Hover bg | slate-800 | 30 41 59 |
| Borders | slate-700 | 51 65 85 |

### Contrast fixes (all now ≥ 4.5:1 on slate-900)

| Class | Old mapping | New mapping | Reason |
|---|---|---|---|
| `.text-slate-300` | slate-600 | slate-400 | 2.2:1 → 5.8:1 (was failing WCAG AA) |
| `.text-slate-400` | slate-500 | slate-400 | 3.5:1 → 5.8:1 |
| `.text-slate-600` | slate-400 | slate-300 | body text lift |
| `.text-slate-700` | slate-300 | slate-200 | mid-heading lift |
| `.text-slate-800` | slate-200 | slate-100 | heading lift |
| `.text-slate-900` | slate-100 | slate-50 | top-heading lift |

### Hover fixes

| Class | Old | New | Reason |
|---|---|---|---|
| `.hover:bg-slate-50` | slate-950 | slate-900 | was same as page bg (invisible) |
| `.hover:bg-slate-100` | slate-900 | slate-800 | was same as card bg (invisible) |
| `.hover:bg-slate-200` | — | slate-700 | new rule |

### Surface + border fixes

- `.bg-slate-100` → slate-800 (was slate-900, merged with cards)
- `.bg-slate-200` → slate-700 (was slate-800)
- `.border-slate-200` → slate-700 (was slate-800, near-invisible on slate-900)
- `.border-slate-300` → slate-600
- `.ring-slate-200` family bumped to slate-700

### Body bg consistency

Added `.dark body { background-color: rgb(2 6 23); color: rgb(241 245 249); }` in `@layer base` so the page surface no longer uses the shadcn `--background` OKLCH neutral — which was a different hue than slate-950 and caused a visible halo at the page edge.

### Extra opacity variants added

`.bg-white/80`, `.bg-white/90` now also map correctly for translucent sticky headers/backdrops.
